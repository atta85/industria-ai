# Hackathon demo script

### 1. Manufacturing
“A CNC-machined aluminum housing develops a 40 micron bore error after several hours. Tool, coolant and temperature data are available.”
Expected routing: Manufacturing + Mechanical Engineering (or Materials if evidence suggests material effects).

### 2. Software
“A production analytics application becomes progressively slower after several hours. CPU is moderate but memory usage grows.”
Expected routing: Software + Data/AI or Operations/Process.

### 3. Biotechnology
“A fermentation batch shows inconsistent yield between otherwise similar runs.”
Expected routing: Chemical Engineering + Quality/Reliability or Operations/Process.

During the demo, explicitly use both human checkpoints to show that the human can modify routing and reject the analysis.
